Как подключить RealtyCalendar

Шаг 1 — Экспорт из RC (RC → ваш сервер):
RC → Менеджер каналов → иконка объекта → iCalendar → скопировать ссылку Экспорт
→ вставить в поле «RC iCal URL» у каждой квартиры ниже

Шаг 2 — Импорт в RC (ваш сервер → RC):
RC → Менеджер каналов → иконка объекта → iCalendar → поле Импорт
→ вставить: https://ВАШ_ДОМЕН/api/ical/apt-1 (для каждой квартиры)

Шаг 3 — Webhook (мгновенные обновления):
RC → Настройки → Интеграция → Webhook
→ вставить: https://ВАШ_ДОМЕН/api/webhook/rc

RealtyCalendar интеграция

RC → Менеджер каналов → иконка объекта → iCalendar → ссылка Экспорт
Эту ссылку вставьте в RC → Менеджер каналов → iCalendar → Импорт. RC будет читать брони с вашего сайта.

Как работает: Ваш сервер каждые 15 мин читает iCal из RC и кэширует занятые даты. При бронировании на сайте — запись идёт в БД, RC подхватит при следующем импорте вашего iCal. При подключении Webhook — RC уведомит ваш сервер сразу при новой брони → мгновенное обновление.
